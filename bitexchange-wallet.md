# BitExchange Hardware Wallet (2014)

An early hardware wallet product that laid the technical foundation and design
philosophy for the subsequent HardID wallet. **Historical product — no longer
manufactured.**

## Technical Specifications

- **Dimensions** — 3.1cm × 2.1cm × 0.43cm. Super slim form factor.
- **Sapphire Glass** — Scratch-resistant sapphire crystal display, premium durability.
- **Touch Screen** — Capacitive touch screen for intuitive interaction.
- **CNC Aluminum** — High-precision CNC aluminum alloy case, robust yet elegant.
- **Dual Security** — PIN code + seed phrase for double-layer protection.
- **Custom Engraving** — Custom laser printing on backside for personalization.

## Key Features

- Easy and secure Bitcoin storage.
- Random private key generation, on-device signing. Private key never touches the network.
- PIN code + seed phrase — double security.
- Fully open-source code, transparent and verifiable.
- Sapphire glass display, scratch-resistant and premium.
- Capacitive touch screen for easy navigation.
- Ultra-slim: 0.43cm thick, 3.1cm × 2.1cm footprint.
- CNC high-precision aluminum alloy case.
- Custom laser engraving on backside.
