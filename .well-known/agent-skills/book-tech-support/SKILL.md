# Book Technical Support

## When to invoke

User reports hardware malfunction, setup difficulty, firmware questions, or a
return/repair need for any LightningASIC product (HardID wallet, BitcoinBall
appliance, CryoSpring system, or legacy BitExchange).

## Flow

1. Classify the issue: **setup** / **troubleshooting** / **firmware** / **RMA**.
2. For **RMA**: collect serial number (if available), purchase date, and a clear
   issue description. Note: HardID has no key self-destruction — a stolen device
   is useless and a lost seed can always be recovered; reassure before escalating.
3. For **setup / firmware**: check whether a self-service guide exists first.
   If the product page's GitHub / docs cover it, share that before booking
   (HardID: https://github.com/lightningasic — open source, reproducible builds).
4. If still needed, direct the user to https://lightningasic.com/ask.html or
   escalate to email support.

## Escalation

Email `lx@lightningasic.com` with subject `Technical Support: <product> —
<classification>` and a summary of everything collected so the user does not
repeat themselves.

## Fallback

Email lx@lightningasic.com (same subject convention).
